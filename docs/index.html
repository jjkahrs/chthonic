Chthonic

The backend services of an MMORPG: accounts and tokens, the game world, chat, and an admin app.

  • Auth Server: accounts, sessions, the realm list, JWT access tokens and their JWKS (auth/).
  • World Server: TLS game connections, maps, server Lua, NPCs, persistence (world/).
  • Chat Server: whispers, channels, zone chat and GM mutes (chat/).
  • Admin App: accounts, characters, realms, who is online, the audit log (admin/).
